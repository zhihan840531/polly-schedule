⚙️ 基本資料維護

🖥️ 開機自動跳出來（電腦）

網頁本身無法控制電腦開機行為，但可以設定瀏覽器「開機自動開啟這個網址」：

  1. Chrome：設定 → 開機時 → 開啟特定網頁 → 新增這個網址
  2. Edge：設定 → 啟動時 → 開啟這些頁面 → 新增這個網址
  3. 若想要「開機就自動跳出」（不用先開瀏覽器）：把瀏覽器捷徑放進「啟動」資料夾（Win+R 輸入 shell:startup），並在捷徑目標後面加上 --app=你的網址，開機會直接跳出獨立視窗。

📱 手機加到主畫面

Safari／Chrome 開啟此網頁 → 分享 → 加入主畫面，之後點主畫面圖示即可像 App 一樣開啟。

✨ AI 辨識金鑰

「教案」頁的 AI 自動整理功能需要 Anthropic API 金鑰（到 console.anthropic.com 申請，屬於用量計費，辨識一張圖大約幾分錢台幣）。金鑰只存在這台裝置的瀏覽器裡，不會上傳到 GitHub。
